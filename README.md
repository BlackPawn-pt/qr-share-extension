# QR-Share — расширение Chrome «QR-код текущей страницы»

![version 1.0.0](https://img.shields.io/badge/version-1.0.0-blue) ![Chrome MV3](https://img.shields.io/badge/Chrome-Manifest%20V3-green) ![MIT](https://img.shields.io/badge/license-MIT-lightgrey)

> Клик по плавающей кнопке — и на экране QR-код текущего URL: с ПК на телефон за одно движение камеры.

## Зачем это нужно

Типичная ситуация: открыл на ноутбуке длинный URL (инструкция на `localhost:3000`, черновик документа, статья) — и нужно быстро перенести страницу на смартфон. QR-Share добавляет на **любую** веб-страницу аккуратную плавающую кнопку, по которой открывается панель с:

- **QR-кодом текущего URL** (200×200, коррекция уровня M);
- адресом страницы мелким шрифтом под кодом;
- кнопками **«Копировать ссылку»** (с фолбэком на `document.execCommand` для http-страниц) и **«Закрыть»**.

## Ключевая техническая деталь: поддержка SPA

Современные сайты (Next.js, Vue Router, приложение Кинопоиска…) меняют `location.href` **без перезагрузки страницы**. Расширение отслеживает смену URL и пересобирает QR-код, если панель открыта, — один из тех нюансов content script'ов, который легко упустить.

## Стек и что показывает проект

| Файл | Роль |
|---|---|
| `manifest.json` | Chrome Manifest V3, content script на всех страницах |
| `content.js` | Инъекция DOM, изоляция через IIFE, конфиг в объекте `CONFIG`, SVG-иконка без внешних ассетов, observer изменения URL |
| `qrcode.min.js` | Генерация кода ([davidshimjs/qrcodejs](https://github.com/davidshimjs/qrcodejs), MIT) |

Что демонстрирует: работу с Chrome Extension API (MV3), содержательную интеграцию в чужой DOM с изолированными ID и `z-index`, аккуратные стили inline, обработку граничных случаев (clipboard-разрешения, SPA-навигация).

## Установка

1. Склонировать репозиторий и распаковать (если скачали zip).
2. Открыть `chrome://extensions` → включить **режим разработчика**.
3. **Загрузить распакованное расширение** → выбрать папку проекта.
4. Кнопка с QR-пиктограммой появится в правом нижнем углу любой страницы.

## Сборка и структура

```
qr-share-extension/
├── manifest.json     # MV3: имя, версия, content scripts
├── content.js        # вся логика (кнопка + панель + SPA)
└── qrcode.min.js     # библиотека генерации QR
```

Ни сборщиков, ни зависимостей — расширение работает «как есть».

## История замысла

Проект вырос из учебного расширения «кнопка-переход для конкретного сайта»: как только UI стал универсальным (QR любого текущего URL), пропала необходимость в целевом домене — осталась удобная утилита без ограничений магазинов расширений, которую можно открыто выложить в репозиторий.
